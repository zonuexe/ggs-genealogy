# 識別子の方針：語彙は w3id.org、データは意味を持たない ID

語彙の述語とクラスの URI はすべてのデータに埋め込まれるため、公開後には変えられない。そこで、ホスティング先や所有ドメインの事情に左右されない恒久 URI サービス w3id.org を使い、語彙の名前空間を `https://w3id.org/ggs/` の下に置く（戸籍オントロジーは `https://w3id.org/ggs/koseki#`）。w3id.org への登録が通るまでも同じ URI を使う。

データ（謄本、記載人物、人物、同定など）の URI は、収集者のワークスペースの base URI に、意味を持たない ID（ULID）を付けて作る。欄と記載は、謄本の URI の下に `謄本ID/欄番号/記載番号` の形で置く。謄本の ID は、取り込むときに一度だけ発行する。

## Considered Options

- **所有ドメインや GitHub Pages を名前空間にする**: ドメインの失効やホスティング先の移行で URI が壊れる。子の世代までデータを残すという目的に合わない。却下。
- **中身から ID を作る（本籍＋筆頭者＋編製日など）**: 本籍や筆頭者は表記ゆれや判読の誤りで後から直すことがあり、そのたびに ID が変わる。却下。
- **連番**: 複数の作業場所で並行して ID を発行すると衝突する。却下。
